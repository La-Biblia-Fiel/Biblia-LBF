# Contribuir a La Biblia Fiel

Este repositorio es el proyecto público de **La Biblia Fiel** (LBF): la traducción, sus fuentes y las ediciones publicadas.

## Licencia y CLA

Lea `LICENSE`, `NOTICE.md` y `CLA.md` antes de enviar un cambio.

- El texto bíblico LBF se publica bajo **CC BY-NC-ND 4.0**.
- El uso comercial (Biblias impresas, aplicaciones, publicaciones) requiere **acuerdo escrito con Cultivados en Gracia y Verdad**.
- Al abrir un *pull request* usted acepta el `CLA.md`. Ese acuerdo otorga a Cultivados en Gracia y Verdad autoridad para relicenciar su contribución, incluso para licencias comerciales.

## Qué es este proyecto

LBF es una traducción al español contemporáneo hecha desde las lenguas bíblicas. El traductor no es el autor. Lea el juramento en `README.md` antes de proponer un cambio.

## Cómo ayudar

- Abra un *issue* para una pregunta, un verso dudoso o un libro que quiera revisar.
- Abra un *pull request* solo con cambios de traducción o de documentación del proyecto.
- Cite el verso y, si puede, el hebreo o el griego que está representando.
- No suavice, no fortalezca y no resuelva tensiones que el texto deja abiertas.

## Qué no va aquí

El motor y la base de alineación inversa son privados. El taller de producción y las verificaciones internas no viven en este repositorio. Aquí está el texto, sus fuentes y las ediciones publicadas.
